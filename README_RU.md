# FServerLobbySpawn

Два модуля: `velocity` отслеживает только переход `minecraft` -> `lobby`; `paper` принимает plugin message и телепортирует игрока на точку из `plugins/FServerLobbySpawn/config.yml`.

Координаты спавна пользователя: world=`world`, x=`-152.156`, y=`71.0`, z=`-119.542`, yaw/pitch пока `0`.

## Сборка через GitHub Actions
1. Создайте пустой GitHub repository.
2. Загрузите **содержимое этой папки** в корень репозитория (файл `pom.xml` должен оказаться в корне).
3. Откройте вкладку Actions и запустите `Build plugin JARs` (или дождитесь запуска после push).
4. Если сборка успешна, откройте запуск workflow, внизу скачайте artifact `FServerLobbySpawn-JARs`.

Артефакт содержит два JAR: `fserver-lobby-spawn-velocity` и `fserver-lobby-spawn-paper`.

## Важно
Это исходники с настройкой автоматической сборки, не готовые JAR. Сборка также проверит доступность заявленных API версий. Если Maven не найдёт Paper API `26.2-R0.1-SNAPSHOT`, не устанавливайте ничего: пришлите лог Actions, подберём точную опубликованную версию API. Не переименовывайте JAR и не загружайте исходники в `plugins`.

Paper-плагин использует канал `fserver:lobbyspawn`. Он получает сообщение только при переходе с backend `minecraft` на `lobby`. Первое подключение через Limbo не должно затрагиваться. Сообщение приходит после подключения к Lobby, поэтому абсолютное отсутствие даже одного кадра со старыми координатами не гарантируется.
